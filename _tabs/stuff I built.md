## Joplin to Todost

[Joplin to Todost](https://joplinapp.org/plugins/plugin/net.thomassloan.joplin-to-todoist/) is a free plug-in I wrote that allows you to create new Todoist tasks directly from inside a Joplin note. It creates a Todoist link in the Joplin note so you can jump to the Todist task directly from Joplin. It also add a Joplin note link in the Todoist task. Definitely worth checking out if you use Joplin and Todoist.
